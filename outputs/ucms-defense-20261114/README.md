# Phân công bảo vệ UCMS

`UCMS_Phan_cong_bao_ve_6_nguoi.xlsx` chuyển bản phân công trong
[`docs/UC_FLOW_GROUPS.md`](../../docs/UC_FLOW_GROUPS.md) sang Excel, gồm bảng phân công,
kịch bản demo và danh sách UC theo người phụ trách.

Điền tên thành viên và tổng thời gian ở sheet `Phân công`. Các ô nhập được tô vàng nhạt.
