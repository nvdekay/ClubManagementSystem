# 02 — Use case model and specification (v2, current)

The authoritative use case material: **54 use cases (UC01–UC54)**, 3 actors, 2 external
systems, 12 modules. All numbering in this folder is v2; the v1 numbering (UC01–UC57) lives
only in [`../01-business-analysis/`](../01-business-analysis/).

| File | What it is |
|---|---|
